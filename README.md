# Virexa AI Technologies

Corporate site source for [virexa-tech.com](https://virexa-tech.com).

Main divisions: CasTech, CasTechLED, CasTech AI.

## Deployment

The static `index.html` website is deployed automatically through GitHub Actions on pushes to `main` using `.github/workflows/deploy-pages.yml`.

Initial GitHub Pages URL (when deployment succeeds): https://blldrmz.github.io/virexa-tech/

Connecting the custom domain `virexa-tech.com` requires its DNS records and the GitHub Pages Custom Domain setting to be configured and verified separately.
